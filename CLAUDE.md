# Pattern Studio

- The whole app is `index.html` (HTML, CSS and JS in one file, no build step).
- To make or export a pattern for someone, read **making_patterns_with_ai.md**: write the pattern JSON, run `node tools/render.mjs pattern.json --format png` to check it, then render the formats asked for and share the `--link`.
- Live site: https://camembert-picante.github.io/pattern_studio/
